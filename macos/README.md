# GlobeRater for macOS

Native SwiftUI app with a menu bar panel and WidgetKit widgets. macOS 14 Sonoma or later.

## Build

Requirements: Xcode 16+, [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

1. Add your Apple ID in Xcode → Settings → Accounts (a free account is enough).
2. `cp Config/Signing.xcconfig.example Config/Signing.xcconfig` and put your Team ID in it.
3. Generate and build:

```bash
xcodegen generate
xcodebuild -scheme GlobeRater -configuration Debug -derivedDataPath build build
```

## DMG

```bash
./scripts/build-dmg.sh            # signed with your Personal Team
ADHOC=1 ./scripts/build-dmg.sh    # ad-hoc signed, for this Mac only
```

An ad-hoc build has no App Group, so the app and the widgets keep separate data (the widgets show their own keypad and budget). Use it to try the UI; use the signed build for real use.

The DMG lands in `build/`. It is not notarized (a free Apple ID can't notarize): on first launch, open *System Settings → Privacy & Security → Open Anyway*.

## Layout

- `GlobeKit/`: logic (rates, keypad, budget periods, expenses, weather, refresh policy), no UI.
- `WidgetUI/`: widget views and App Intents, compiled into both the app (gallery) and the extension.
- `GlobeRater/`: the app: window, settings, menu bar panel.
- `GlobeRaterWidgets/`: the WidgetKit extension.
- `Shared/Localizable.xcstrings`: generated by `python3 ../tools/gen_xcstrings.py` from the Android translations.

## Tests

The logic lives in the `GlobeKit` package and is tested on its own:

```bash
cd GlobeKit && swift test
```
